Разговоры, память Claude и настройки хранятся в скрытой папке приложения на вашем Google Диске (доступ drive.appdata: расширение не видит ваши файлы). Так они появятся на другом телефоне или компьютере с этим расширением.

Client ID и Client secret Google (нужны один раз)
  1. Откройте console.cloud.google.com → создайте проект.
  2. «APIs & Services → Library» → включите Google Drive API.
  3. «OAuth consent screen» → External → заполните название и почту → в «Test users» добавьте свой Gmail.
  4. «Credentials → Create credentials → OAuth client ID» → тип Desktop app → скопируйте Client ID и Client secret сюда.

Ключ хранится только в этом браузере и отправляется только на api.anthropic.com. Запросы оплачиваются по тарифам API Anthropic (отдельно от подписки claude.ai). Ввод в поля паролей и карт всегда требует вашего подтверждения.
