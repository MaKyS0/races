# Claude Browser Agent: расширение для Firefox на Android (неофициальное)

Чат с Claude прямо в Firefox. Claude может читать открытую страницу и действовать на ней: нажимать, вводить текст,
прокручивать, открывать адреса, переключать вкладки. Работает через **ваш API-ключ Anthropic** (console.anthropic.com).
Это отдельная оплата по тарифам API, не подписка claude.ai. Расширение неофициальное, Anthropic его не выпускала.

## Как пользоваться

1. Откройте сайт, с которым нужно что-то сделать.
2. Откройте меню Firefox → **Дополнения / Расширения** → **Claude**. Откроется вкладка с чатом. Вверху видно,
   с какой страницей работает Claude: это последняя открытая вкладка с сайтом.
3. При первом запуске вставьте API-ключ (⚙ → «API-ключ Anthropic»), выберите модель и «усилие».
4. Пишите, например: «перескажи статью», «найди на сайте телефон поддержки»,
   «заполни поиск: билеты Москва — Казань на пятницу».
5. Перед каждым нажатием, вводом или переходом появляется вопрос «Разрешить / Запретить». Это можно выключить
   в настройках. Ввод в поля паролей и карт **всегда** требует вашего подтверждения.
6. ■ останавливает Claude. ＋ начинает новый разговор.

Что умеет Claude (инструменты): `get_page` (текст и пронумерованные элементы страницы), `click`, `type_text`
(в том числе выбор в выпадающем списке и Enter), `scroll`, `navigate`, `go_back`, `list_tabs`, `switch_tab`, `open_tab`.

### Синхронизация с Google и память Claude

- **Память.** Claude сам сохраняет то, что стоит помнить («запомни, что я живу в Казани»), инструментом `remember`
  и удаляет заметки инструментом `forget`. Заметки видны в каждом новом разговоре на всех устройствах. Посмотреть,
  добавить и удалить их можно кнопкой ✦. Пароли и коды Claude сохранять не должен. По просьбе сайта он ничего
  не запоминает.
- **История.** Кнопка ☰ открывает список разговоров (до 40). ＋ начинает новый разговор, старый остаётся в истории.
- **Google.** ⚙ → «Синхронизация с Google» → «Войти через Google». Разговоры, память и настройки хранятся одним
  файлом в скрытой папке приложения на вашем Google Диске (доступ `drive.appdata`: остальные файлы Диска
  расширению не видны). Синхронизация идёт при открытии чата, через несколько секунд после каждого изменения,
  раз в 10 минут и по кнопке. При правке на двух устройствах для каждого разговора, заметки и настроек побеждает
  более новая версия. Удаления тоже синхронизируются. API-ключ синхронизируется, только если включить
  «Синхронизировать и API-ключ».
- **Один раз нужен свой Client ID Google** (Google не разрешает входить без него). На console.cloud.google.com:
  1. Создайте проект и включите **Google Drive API**.
  2. В «OAuth consent screen» выберите External и добавьте свой Gmail в «Test users».
  3. В «Credentials → OAuth client ID» выберите тип **Desktop app**.
  4. Вставьте Client ID и Client secret в настройки расширения.

  Вход идёт через вкладку Google. Расширение перехватывает возврат на `http://127.0.0.1:53682/oauth2`: там ничего
  не запущено, адрес нужен только чтобы забрать код. API `identity` для этого в Firefox для Android нет.
- **«Синхронизация с Claude»** — это общая память и история между вашими устройствами. С чатами на claude.ai
  расширение не связано: у claude.ai нет открытого API для сторонних приложений.

### Безопасность

- Ключ хранится только в этом браузере (`storage.local`) и уходит только на `api.anthropic.com`.
- Текст страниц передаётся Claude в пометке «это содержимое сайта, а не инструкции». Если сайт пытается командовать,
  Claude не должен этого выполнять и сообщит вам. Полной защиты от такой «инъекции» нет, поэтому подтверждения
  действий по умолчанию включены. Не выключайте их на сайтах с деньгами и личными данными.
- Страницы `about:` и магазин дополнений Firefox расширениям недоступны.

## Установка на телефон

Firefox для Android (обычная версия) ставит только **подписанные** дополнения. Варианты:

**A. Подписать как «неопубликованное» (unlisted) на addons.mozilla.org.** Бесплатно и без публикации в каталоге.
1. Войдите на addons.mozilla.org. В «Developer Hub → Manage API Keys» получите JWT issuer и secret.
2. На компьютере выполните в этой папке:
   `npm ci && npm run build && npx web-ext sign --source-dir dist --channel unlisted --api-key <issuer> --api-secret <secret>`.
   Подписанный `.xpi` появится в `web-ext-artifacts/`.
3. Перенесите `.xpi` на телефон. В Firefox: Настройки → «О Firefox» → 5 раз нажмите на логотип (включится меню
   отладки) → назад в Настройки → «Установить дополнение из файла» → выберите `.xpi`.

**B. Firefox Nightly на телефоне** позволяет ставить неподписанные файлы: в `about:config` выставьте
`xpinstall.signatures.required = false`, затем «Установить дополнение из файла» → `claude-browser-agent-0.1.0.xpi`.

**C. Для разработки:** телефон по USB с включённой отладкой, на компьютере
`npx web-ext run -t firefox-android --source-dir dist --android-device <id>`. Расширение работает до перезапуска Firefox.

## Сборка и проверки

```bash
npm ci
npm run build      # dist/: manifest, background.js, chat.html/js/css
npm run typecheck  # TypeScript
npm test           # 22 теста: цикл агента (скриптовая модель), функции страницы в Chromium, слияние данных двух
                   # устройств, вход Google и Drive против мок-сервера; сквозные: чат + фоновый скрипт + настоящий
                   # Anthropic SDK против мок-API (SSE), и два «устройства» с одним Google-аккаунтом
npm run lint       # web-ext lint (0 ошибок; 5 предупреждений про innerHTML: весь текст экранируется)
npm run package    # web-ext build: неподписанный архив в artifacts/
```

Устройство: `src/store.ts` (разговоры, заметки, правило слияния устройств), `src/google.ts` (вход Google с PKCE,
файл на Диске), `src/background.ts` (постоянная фоновая страница, держит разговоры, память, синхронизацию и цикл агента, вызывает
`claude-opus-5-5` через `@anthropic-ai/sdk` со стримингом, server-side fallbacks и очисткой старых результатов
инструментов), `src/agent.ts` (цикл: каждый `tool_use` получает `tool_result`; отказ, обрезка по длине и остановка
обрабатываются), `src/tools.ts` (инструменты, подтверждения, `tabs.executeScript`), `src/page.ts` (функции, которые
выполняются на странице), `src/chat.ts` + `static/` (интерфейс под телефон, светлая и тёмная тема).

**Что не проверено:** расширение не запускалось в настоящем Firefox для Android: здесь нет ни телефона, ни Firefox.
Тесты гоняют те же файлы в Chromium с имитацией API браузера. К настоящим API Anthropic и Google запросов не было:
нет ключей и Client ID. Форматы запросов (вход OAuth с PKCE, обмен кода, обновление токена, файл в appDataFolder)
проверены на мок-серверах по документации Google.
