# Apex GP Simulator

3D-симулятор гонок класса Formula 1 с упором на физику, а не на аркаду. Один код для ПК (браузер), Android и iOS
(Capacitor). Всё — собственная физика болида (без физических движков), Three.js для рендера, никаких внешних ассетов:
текстуры, трассы и звук генерируются процедурно. Команды и пилоты вымышленные.

> **Статус честно.** Игра собирается, работает в браузере, проходит 99 автотестов. Debug- и подписанный (тестовым
> ключом) release-APK действительно собраны на Linux. **IPA не собирался** (нужен Mac + Apple Developer). **Ни на одном
> реальном телефоне игра не запускалась** — цифры FPS/нагрева/батареи для устройств не измерены. Подробности —
> [docs/STATUS.md](docs/STATUS.md).

## Быстрый старт

```bash
npm ci
npm run dev        # http://localhost:5173  (vite --host, доступно по сети для проверки с телефона)
npm test           # 99 тестов: физика, трассы, столкновения, ИИ, гонка, ввод/кнопки, сцепление на выходе из поворота
npm run build      # статика в dist/
```

Требуется Node ≥ 20. Для Android/iOS — см. [docs/BUILD.md](docs/BUILD.md).

## Что внутри

**Физика (120 Гц, фиксированный шаг, интерполяция при рендере)**
- Двигатель + КПП: кривая момента, ограничитель оборотов, 8 передач, сцепление, пробуксовка колёс, ERS (MGU-K) и топливо.
- Аэродинамика: прижим ∝ v², сопротивление, слипстрим, «грязный воздух», DRS, влияние клиренса и повреждений.
- Шины: составы Soft/Medium/Hard/Inter/Wet, температура (поверхность/ядро), износ, комбинированное проскальзывание
  (формула Пачейки), аквапланинг, проколы, зависимость от покрытия (асфальт, поребрик, трава, гравий, пит-лейн).
- Тормоза: прогрессивное давление, баланс, нагрев/фейд дисков, ABS (только если включён ассист), рекуперация.
- Подвеска: тангаж/крен/вертикаль (3 степени свободы), стабилизаторы, перенос нагрузки, отклик на поребрики и неровности.
- Столкновения: импульсы в точке контакта, OBB машина↔машина, стены, модель повреждений по узлам (передние/задние
  крылья, днище, подвеска, колёса, силовая установка), отрыв деталей, снятие с гонки.
- Флаги: жёлтые, Safety Car, VSC, штрафы за лимиты трассы, столкновения, превышение скорости в пит-лейне.

**Контент**
- 6 трасс с собственной геометрией, профилем высот, поребриками, зонами выбега, стенами, пит-лейном, сеткой и DRS:
  Monaco, Monza, Spa-Francorchamps, Silverstone, Suzuka, Bahrain (вдохновлены реальными, но это не копии).
- Режимы: Time Trial (с призраком), Practice, Qualifying, Grand Prix, Championship (календарь + очки).
- Погода: сухо / лёгкий дождь / ливень / динамическая; лужи, аквапланинг, молнии, брызги.
- 10 вымышленных команд, 20 пилотов, 4 уровня сложности.

**ИИ-соперники** используют тот же `Vehicle`, что и игрок, и управляют только педалями и рулём: racing line
(минимальная кривизна), профиль скоростей по трению, следование (IDM-подобное с учётом торможения лидера), слой
предсказания столкновений (TTC), атаки и защита, ошибки под давлением, пит-стопы с выбором шин, обход вылетевших машин.

**Интерфейс и управление**
- HUD: скорость, обороты, передача, круги/позиция, тайминг, дельта, шины (температура/износ), тормоза, топливо, ERS,
  DRS, флаги и сообщения, миникарта, погода, повторы.
- Клавиатура, геймпад, сенсор, переназначение клавиш, чувствительность/линейность/мёртвая зона, ассисты (ABS, TC, помощь рулём,
  карта давления тормозов, авто-КПП, линия) — физику они не заменяют.
- **Сенсорное управление — только цифровые кнопки:** GAS справа внизу, BRAKE левее, руль ◀ ▶ слева, плюс PIT/ERS/DRS/камера/передачи/пауза.
  Держишь — газ/тормоз, отпустил — снято. Одновременное нажатие (мультитач), сброс при потере фокуса. Размер, прозрачность и
  положение каждой кнопки настраиваются (Settings → Touch → Edit layout). Подробности и результаты проверок:
  [docs/CHANGELOG-physics-controls.md](docs/CHANGELOG-physics-controls.md).

| Действие | Клавиша по умолчанию |
|---|---|
| Газ / тормоз | W, ↑ / S, ↓ |
| Руль | A, D / ←, → |
| Передачи | E (вверх), Q (вниз), T (авто/ручная) |
| DRS / ERS / питлейн-лимитер | Space / G / L |
| Заезд в боксы | B |
| Баланс тормозов, блокировка дифференциала | [ ] , . |
| Камера / карта / оглянуться / повтор | C / M / X / V |
| Сброс машины (практика) / пауза / FPS | R / Esc,P / F3 |

## Производительность и мобильные устройства

- Профили Low / Medium / High (тени, разрешение, дальность, плотность декора, LOD машин, частицы, IBL).
- Целевая частота: авто / 30 / 60 / 90 / 120 FPS с ограничителем кадров.
- Динамическое разрешение (0.5–1.0), «термо-регулятор» (уровни 0–3): сам снижает нагрузку при перегреве/просадке,
  но не обходит троттлинг ОС. Источник температуры — нативный плагин `Thermal` (Android `PowerManager`,
  iOS `ProcessInfo.thermalState`) — **код написан, на устройстве не проверен**.
- Чанки трассы с hi/lo LOD, инстансинг декора, пул частиц, инстансинг следов шин, GPU-дождь.
- Физика всегда идёт на 120 Гц для всех машин; огрубление (2×) включается только на уровне регулятора 3.

## Лицензия и ассеты

Внешних ассетов нет: геометрия, текстуры и звук строятся кодом. Названия трасс — только ориентир; команды, пилоты и
логотипы вымышлены. Стороннее ПО — Three.js (MIT), Capacitor (MIT).
