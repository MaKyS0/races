# Архитектура

## Главный цикл (`src/Game.js`)

```
requestAnimationFrame
  └─ Perf.shouldRender()          ограничитель кадров 30/60/90/120 (авто: измеряет частоту дисплея)
      ├─ накопитель времени → до 6 шагов (4 при уровне регулятора ≥ 2) по 1/120 с:
      │     RaceManager.step(dt)  ИИ → физика → столкновения → тайминг → правила
      ├─ alpha = остаток/шаг     интерполяция положения/ориентации машин для рендера
      ├─ CameraController, Renderer (динамическое разрешение), HUD
      └─ Perf.endFrame()          динамическое разрешение, регулятор нагрузки, статистика
```

Физика не зависит от частоты кадров: рендер только интерполирует между двумя последними состояниями (`Vehicle.prev`).
Если кадр затянулся, шагов не больше 6, лишнее время отбрасывается (никаких «спиралей смерти»).

`RaceManager.step()` → `stepWorld()` (контекст ИИ, шаг физики машин, столкновения, тайминг) → `stepRules()` (порядок,
пит-стопы, лимиты трассы, флаги, SC/VSC, программы квалификации, возврат на трассу, DRS, финиш).

## Соглашения

Единицы СИ, метры. Вперёд = (sinψ, cosψ); влево = (cosψ, −sinψ); +ψ — поворот налево; поперечная координата `n`
положительна слева от осевой линии; колёса по порядку FL, FR, RL, RR.

## Физика (`src/physics`)

| Модуль | Что делает |
|---|---|
| `VehiclePhysics.js` | Плоское твёрдое тело (u, v, r) + вертикаль/тангаж/крен. Нагрузки на колёса: статика + аэро + продольный и поперечный перенос (геометрический и упругий, стабилизаторы). Интеграция колёс полунеявная с локальным наклоном кривой силы (устойчива на низких скоростях). Дифференциал с preload/power/coast. Рельеф: возмущения от поребриков, фильтр 25 Гц. |
| `EngineAndTransmission.js` | ДВС ~500 Н·м, ограничитель, 8 передач (ряд 19.6 … 5.45), проскальзывающее сцепление (передаёт только положительный момент), торможение двигателем, MGU-K 120 кВт / 4 МДж, расход топлива. |
| `Aerodynamics.js` | ClA ≈ 3.5–5.4 и CdA ≈ 0.9–1.7 в зависимости от крыльев/DRS/повреждений, влияние клиренса, слипстрим и грязный воздух (`computeWake`). |
| `TireModel.js` | Составы (μ₀: Soft 2.62 … Wet 2.05, окно температур), кривая Пачейки (B=2, C=1.5, E=0.3) с комбинированным скольжением, чувствительность к нагрузке, релаксация, тепло/износ, влажность, аквапланинг, проколы. |
| `BrakeSystem.js` | Давление с задержкой, баланс, КПД колодок от температуры (холодные и перегретые тормоза), нагрев/остывание дисков, ABS (по ассисту), компенсация рекуперации. |
| `CollisionAndDamage.js` | Широкая фаза по сетке, OBB-контакты с импульсом в точке касания (трение, восстановление), стены с учётом пит-лейна, модель повреждений и отказов, отрыв деталей, события для звука/эффектов. |

## Трасса (`src/track`)

Конвейер: черепашья геометрия сегментами (`Turtle`) → точное замыкание (одна свободная кривая гасит ошибку курса, прямые —
ошибку положения) → равномерная передискретизация 2 м → высоты (Catmull-Rom) → сечение: ширина, поребрики, зоны выбега
(асфальт/гравий/трава), стены (внутренние стены ограничены радиусом поворота) → пит-лейн (въезд/полоса/выезд, боксы, у
въезда/выезда нет барьера) → racing line (минимальная кривизна с границами) → профиль скоростей (проход вперёд/назад по
кругу трения). `Locator` даёт быстрый поиск положения машины на трассе. `validate()` проверяет замкнутость,
самопересечения и стены; тесты прогоняют все шесть трасс.

## ИИ (`src/ai`)

`DriverAI.update()` выставляет только `throttle/brake/steer/drs`.

1. Целевая линия: racing line + боковое смещение. Смещение ограничено (±3.6 м при обгоне), не начинается перед тормозной
   зоной, плавно меняется (ограничение боковой скорости), учитывает расстояние до стены.
2. Руль: упреждение по кривизне + обратная связь Стэнли + контр-руление при заносе + ограничение по кругу трения.
3. Скорость: профиль × мастерство × темп × грип (шины/повреждения/аэродинамика) × ошибки.
4. Следование: желаемая дистанция растёт со скоростью и с сближением, торможение лидера учитывается заранее.
5. Слой TTC: для всех соседних машин (и остановившихся) — предсказание касания с постоянной скоростью, торможение, если оно
   неизбежно; не зависит от «полосы».
6. Пит-стопы: автомат (ENTRY → TOBOX → SERVICE → EXIT), «светофор» на выезде при быстром трафике, плавная вставка на трассу.
7. Ошибки (перетормаживание, резкий газ) — вероятность зависит от мастерства, давления и сложности.

Диагностика ИИ — `scripts/ai-diag/*` (разбор первых инцидентов, горячие точки, классификация причин).

## Гонка (`src/race`)

`RaceManager` — сессии (практика, квалификация, гонка, Time Trial), старт со светофором, порядок и тайминг, DRS (зоны; в гонке — с 3-го круга, при зелёном флаге и без сильной воды на трассе; допуск определяется на детекторе:
отставание от машины впереди < 1 с), пит-стопы, шины и топливо, погода → состав шин, жёлтые флаги, SC (колонна за машиной безопасности),
VSC, штрафы, повторы и призрак, «маршалы» (возврат застрявших, уборка остановившихся машин, разрыв затора).
`Championship` — календарь, очки, сохранение.

## Рендер (`src/render`)

Three.js. Трасса — чанки с двумя уровнями детализации; декор (трибуны, деревья, ограждения, знаки) — инстансинг по
«вёдрам»; машины — LOD0/1/2; частицы — пул с собственным шейдером; следы шин — инстансы; дождь — на GPU. Освещение:
PMREM-окружение (с проверкой, что оно не чёрное, — иначе IBL отключается), одна карта теней от солнца, следящая
за камерой/машиной, контактные тени-блобы под машинами. Все текстуры процедурные (`Textures.js`).

## Производительность (`src/core/Perf.js`)

- `QUALITY` Low/Medium/High; `auto` выбирает по числу ядер/памяти/типу устройства.
- Целевой FPS: авто/30/60/90/120.
- Динамическое разрешение: медленнее бюджета на 12 % > 1 с → шаг вниз (до 0.5), быстрее на 28 % > 4 с → вверх.
- Регулятор уровня 0–3 (вниз быстро, вверх через 90 с стабильности); триггеры — температурное состояние платформы,
  длительные просадки при минимальном разрешении, заряд < 15 %. На уровне 3 физика далёких машин может идти шагом 2×
  (`RaceManager.physLod`) и качество падает до Low.
- Память: следим за `performance.memory` (Chrome), считаем сбросы кучи.

Подробно о том, что измерено и что нет, — [STATUS.md](STATUS.md).
