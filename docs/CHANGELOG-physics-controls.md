# Физика, управление, графика — что изменено и как проверено

Доработка существующего проекта; игра не переписывалась, функции не удалялись.

## 1. Заносы на выходе из поворота — причина и исправление

**Воспроизведение** (`scripts/phys/corner-test.mjs`: «водитель» держит заданный радиус по угловой скорости, газ задаётся профилем).
Выход из медленного поворота (R = 35 м, 18 м/с) разворачивало на ~84° при любом уровне TC — **даже при плавном нарастании газа**.

**Причины (найдены измерением, а не подбором коэффициентов):**

1. *Момент не привязан к сцеплению.* Во 2-й передаче на колёсах ~7 кН·м, а задние шины в повороте могли передать ~3,5–4 кН·м.
   Лишний момент раскручивал колесо за ~50 мс (инерция колеса мала), после пика шина отдаёт лишь ~70 % сцепления, а момент
   остаётся выше → колесо «убегало» и удерживалось в буксовании, боковая сила пропадала → разворот. Классический TC реагировал
   слишком поздно (реакция 25 Гц + порог по проскальзыванию).
2. *Тормозной момент вычитался вне полунеявной схемы колеса.* Момент шины делился на (1+a), тормоз — нет, поэтому заблокированное
   колесо шина физически не могла «раскрутить» обратно: при цифровом тормозе колёса были заблокированы ~85 % торможения.
3. *Нет разграничения «педаль / то, что может шина»* для цифровой кнопки, которая выдаёт 100 %.

**Что сделано** (`src/physics/VehiclePhysics.js`, `BrakeSystem.js`):

- **Тяговый бюджет (drive-by-wire карта момента).** Перед передачей момента на колёса считается круг трения каждой ведущей шины:
  `sqrt((μ·Fz)² − Fy²)·R`, где μ — температура/износ/покрытие/вода, Fz — статика + перенос масс + прижим (сглаженная, 25 Гц),
  Fy — боковая сила, которую ось должна удержать (кинематически, чтобы скользящая шина не «освобождала» продольный запас).
  Из момента вычитается часть, уходящая на раскрутку трансмиссии. Допуск над 1,0 зависит от ассиста: TC 2 = 0,9, TC 1 = 0,97,
  TC 0 = 1,12 (небольшая пробуксовка возможна, срыв — при резкой педали). Бюджет падает мгновенно, растёт ограниченно;
  при сильной пробуксовке (κ > 0,22) момент дополнительно снижается, чтобы колесо вернулось в сцепление, а не «залипало».
- **Тормоз внутри схемы колеса** и **карта давления тормозов** (`assists.brakeHelp`, включена по умолчанию): потолок давления
  по каждой оси из круга трения (перенос масс, прижим, боковая загрузка, температура/дождь, КПД колодок). Педаль 1,0 = «максимум,
  что держат шины», 0,5 = половина; баланс тормозов по-прежнему задаёт распределение ниже потолка; заблокированное колесо
  разгружается до восстановления вращения.
- AI-машины используют ту же физику; уровень TC для них 1 (как у игрока по умолчанию).

**Сохранено:** потеря сцепления на слишком высокой скорости (устойчивый недовиражаж: руль в упоре, ошибка по курсу), блокировка
колёс при неправильном торможении (`brakeHelp = 0`), пробуксовка при резком газе и TC 0, мокрая трасса.

| Сценарий (TC 1) | До | После |
|---|---|---|
| Плавный газ, выход из R35 | β 84°, разворот ~1 с | β 2,3°, κ 0,11 |
| Резкий газ, выход из R35 | β 84°, разворот ~1,5 с | β 2,2°, κ 0,12 |
| Шпилька R20, резкий газ | β 84° | β 4,6° |
| Мокрая трасса (0,25), слики, плавный газ | β 81° | β 2,0° (скорость ниже) |
| TC 0, плавный газ из R35 | разворот | β 2,3°, пробуксовка κ 0,21 |
| Старт с места, полный газ, поворот руля до упора | β 72–79° | β 9–10° |
| Блокировка колёс при торможении 80 м/с (ABS выкл.) | 2,5 с из 2,9 с | 0,07 с |
| Остановка с 80 м/с | 91 м, пик 5,7 g | 92 м, пик 5,4 g |
| 0–100 км/ч (TC 1 / TC 0) | 2,4 с | 2,6 с / 2,3 с |

## 2. Управление: только цифровые кнопки

`src/ui/TouchControls.js` (переписан), `src/core/Input.js`, `src/Game.js`, `src/ui/style.css`, `src/ui/Menu.js`, `src/core/Settings.js`.

- **Удалены** аналоговые педали, полосы-заливки и всё, что требует двигать палец. Остался виртуальный руль как *необязательный*
  стиль («Virtual wheel», по умолчанию выключен) и гироскоп.
- **GAS** — справа внизу, **BRAKE** — левее GAS, **руль** (◀ ▶) — слева. Размер от 92 px, кнопки не перекрываются.
  Дополнительные кнопки (PIT, ERS, DRS, камера, передачи, пауза) — отдельным рядом.
- Нажал-держишь = газ/тормоз; отпустил = действие прекращается (газ спадает за ~0,17 с, дальше машина катится по инерции;
  тормозное давление растёт и спадает по физике системы, остановки «мгновенно» нет).
- **Мультитач:** каждая кнопка ловит свои pointer-события (`setPointerCapture`), одновременно работают руль + газ/тормоз.
  Если на кнопке несколько пальцев, она держится до поднятия последнего.
- **Нет «залипания»:** сброс всех нажатий при `pointerup/cancel`, `lostpointercapture`, `touchend/touchcancel` (без касаний),
  `blur`, `pagehide`, `visibilitychange`, при паузе/меню/повторе/скрытии контролов; нажатие короче кадра защёлкивается на один кадр.
- Редактор раскладки (Settings → Touch → Edit layout): перетаскивание, ползунки **размера** и **прозрачности** для выбранной кнопки,
  Reset/Done; плюс глобальные размер/прозрачность. Хранится в настройках (версия раскладки 2; старые раскладки игнорируются).
- Телеметрия-«педали» в HUD на тач-устройствах скрыта, чтобы не путать с кнопками.

## 3. Производительность и FPS

- Ввод: опрос геймпада/кнопок — раз за кадр (`Input.sample`), сглаживание педалей/руля — **раз за фиксированный физ. шаг 1/120 с**
  (`Game.stepDrive`), поэтому ощущение одинаково на 30/60/120 FPS. Тяжёлых вычислений в кадре не добавлено; бюджеты момента
  и тормозов — несколько умножений на ось за шаг, аллокаций нет.
- Реальное время теперь держится до 15 FPS (до 20 при троттлинге); ниже — симуляция замедляется, физика не меняется.
- Физика всегда 120 Гц для всех машин (огрубление 2× только на самом тяжёлом уровне регулятора).

`Sky.js`, `Renderer.js`, `TrackMesh.js`, `CarModel.js`, `style.css`, `Game.js`.

  становился почти чёрным**.

## 6. «Безумные заносы на малой скорости» (последняя итерация)
Воспроизведено развёрткой `scripts/phys/lowspeed-test.mjs` (руль/газ/тормоз из 0–25 м/с, асфальт/трава/гравий/мокрая трасса, TC 0–2).
На сухом асфальте с ассистами по умолчанию заносов не было; найдены и исправлены другие причины:
1. **Торможение двигателем блокировало задние колёса.** Сброс газа на низкой передаче с повёрнутым рулём на мокрой трассе на слика́х
   мгновенно разворачивал машину (β 60–70° при 54–90 км/ч). Теперь тормозной момент двигателя ограничен тем, что задние шины ещё могут
   отдать с учётом боковой силы (карта «engine brake»); колесо, которое уже блокируется, получает меньше. Было 6 из 54 сценариев со срывом, стало 0.
2. **Тряска вне трассы.** Неровность травы/гравия/песка (±2,5 кН на колесо при нагрузке 2,5 кН) отрывала колёса от земли и раскручивала
   машину уже на 8 м/с; амплитуда уменьшена (0,012 → 0,005 м), профиль поребрика смягчён.
3. Допуск «инерционного» момента в тяговом бюджете больше не может питать сам себя (ограничен 50 % бюджета).
Что **не** изменено: с выключенным TC и полным газом при повороте руля машину по-прежнему можно развернуть (так и задумано);
на гравии/песке полный газ с рулём срывает машину (рыхлое покрытие). Проверка: 4 новых теста (падают без исправлений), AI-гонки:
тяжёлых ударов 113 → 79 на 40 гонках. На реальных устройствах и «на ощупь» не проверялось.
